# Third-party safety database notice

The JSON files in this directory are adapted from the safety database in
[glitchsumon/DroidDebloater](https://github.com/glitchsumon/DroidDebloater/tree/main/safety-db).
The upstream project is licensed under the MIT License; the license text is
preserved in `LICENSE-DroidDebloater.txt`.

These records are community-authored guidance, not authoritative compatibility
data. Package versions, OEM firmware, and dependencies change. DroidLab treats
the entries as informational guidance, keeps unknown packages unknown, enforces
its own core-package protections, and requires confirmation before changing a
device. A “low” rating is not a guarantee that removal is safe.

Upstream repository: https://github.com/glitchsumon/DroidDebloater
Upstream data paths: safety-db/android.json, safety-db/samsung.json,
safety-db/realme.json, safety-db/xiaomi.json
